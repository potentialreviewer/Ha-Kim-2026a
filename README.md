# Ha-Kim-2026a
Code and data for the paper: Semantic Networks as Clues: A Theoretical Foundation and Process Optimization for Semantic Network Construction

Although ClueNetwork, proposed in the paper, serves as a reusable framework, it has not yet been implemented as a software library. Given that developing such a library requires efforts distinct from proposing the framework itself, it will be presented in a separate publication. This repository contains the code and data used for the experiments in proposing the framework.
